## Tujuan UAT

Evaluator diminta menilai apakah geoportal sudah mudah digunakan dan sesuai kebutuhan dasar untuk:

1. mencari dataset,
2. melihat preview spasial,
3. memfilter area,
4. mengunduh data,
5. mengelola impor data jika evaluator berperan sebagai admin.
